# Context — reference sources

Third-party source trees kept here for reference while working on this
launcher. They are not part of the `vanilla_wow_launcher` package, not
packaged, and not executed by the app.

## OctoLauncher

The official OctoWoW launcher (Electron + React + TypeScript), cloned from
`https://octowow.st/git/octocontr/OctoLauncher` (shallow clone, `.git`
removed) for reference. See its own `README.md` / `BUILD.md` / `LICENSE`
inside `OctoLauncher/`.
